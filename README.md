# Cognifyz Internship – Level 1

## Overview
This repository contains my solutions for Level 1 tasks completed as part of the Cognifyz Technologies Internship. These tasks helped me practice basic Python programming and problem-solving concepts.

## Level 1 Tasks

### Task 1 – String Reversal
This task reverses a given string using Python. It helps in understanding string manipulation and slicing.

*Example:*
Input: Hello  
Output: olleH

### Task 2 – Temperature Conversion
This task converts temperature from Celsius to Fahrenheit and vice versa using the appropriate conversion formulas.

*Example:*
Input: 25°C  
Output: 77°F

### Task 3 – Email Validator
This task checks whether an entered email address follows a valid email format. It helps in understanding string handling and validation.

*Example:*
Input: example@gmail.com  
Output: Valid Email

### Task 4 – Calculator
This task performs basic arithmetic operations such as addition, subtraction, multiplication, and division based on the user's choice.

*Operations:*
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

### Task 5 – Palindrome Checker
This task checks whether a given word or string reads the same forward and backward.

*Example:*
Input: madam  
Output: Palindrome
